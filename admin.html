内容管理台

登录后可以用更像写 Blog 的方式维护文章、个人信息和联系方式，并保存到 GitHub 仓库。

未登录：粘贴 Token 后可连接 GitHub。

使用 YAML 头部维护 type/status/updated/tags。正文里 `#` 是标题，标题后的第一段会作为列表摘要，`## Links` 下面写 `- 标题 | 链接`。

`#` 是欢迎标题，开头第一段是首页简介；`## About`、`## Now`、`## Facts` 会分别写入主界面的档案、当前状态和字段列表。

每行一条：`- 标题 | 值或链接 | 点开后显示的文字`。链接以 `https://` 或 `mailto:` 开头会在新标签页打开。
